# Overhead visual studies

Open `overhead-panels.html` directly in a browser for previews beside the supplied reference images. Each `*-overhead-static.html` is a standalone HTML/CSS document with no React, runtime scripts, network requests, or build requirement. The gallery uses a small script only to switch the displayed files.

These static files remain the reference source for visual refinement. Do not regenerate them from the React components: the static layouts retain finer geometry that can be brought across as focused patches. The aircraft React panels are now selected by ICAO/model through `../src/components/OverheadPanel.jsx`; simulated equivalents remain interactive and unsupported hardware remains visibly INOP. The 747 page is generated by `../scripts/build_747_overhead_preview.py`; A330, A350 and A380 are generated by `../scripts/build_airbus_overhead_previews.py`. Both generators use explicit panel coordinates rather than flex or grid distribution.

The static lighting is illustrative, not a validated operating configuration. The pages are visual review artifacts, not integration-ready system specifications.

Protected controls are drawn as one physical assembly containing its cover, actuator, and staged position legend. Fire handles retain their pull-and-turn stages. Multi-position mode, crossbleed, trim-feed, engine-start, pressurization, and lighting selectors use rotary or toggle hardware rather than generic pushbuttons.
